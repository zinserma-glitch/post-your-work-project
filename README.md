# Project Bikeshare

This bikeshare project analyzes bikeshare usage data to find patterns in travel time, popular stations, and user types. 

## Information about how to use your project

Make sure Python is installed, then run the following command in the terminal:
```bash
python bikeshare_starter.py

The user is asked to choose a city, a month, and a day of the week to filter the bikeshare data. The program then displays statistics based on the selected filters.
